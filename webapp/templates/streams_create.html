Create Stream

Relay a live source into HLS. The stream starts stopped — press Start when ready.

Use a normal name - spaces and punctuation are converted to a safe internal ID automatically (e.g. "My Promo Stream" becomes "my-promo-stream").

Direct sources are handed straight to FFmpeg: HLS (.m3u8), HTTP/HTTPS media, RTMP / RTMPS and RTSP. The URL is stored as data only and never executed by the shell.

Public webpage sources supported by the installed resolver (yt-dlp) — for example YouTube Live pages (youtube.com/watch, youtube.com/live, youtu.be) or other public streaming pages. BlueStream re-resolves the current playable media URL each time you press Start (public content only). A plain website that the resolver does not support will not work.
